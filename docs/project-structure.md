# Project Structure

This repository is organized into folders based on learning goals.

- ai-notes: Machine learning and AI concepts.
- python-practice: Small Python exercises.
- mini-projects: Practical command-line applications.
- prompts: Useful AI prompts for development.
- learning-log: Daily progress.
- tests: Unit tests.
- docs: Project documentation.

The goal is to continuously improve both programming skills and software engineering practices.
